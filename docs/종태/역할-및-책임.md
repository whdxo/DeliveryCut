## 🎯 주요 역할

### 1️⃣ AI/Prompt Engineer (주 담당)

#### 📌 담당 영역
- OpenAI API 통합 및 관리
- 프롬프트 설계 및 최적화
  - System Prompt: 역할, 제약사항, 출력 형식
  - User Prompt: 사용자 입력 변환
- JSON 스키마 정의 (Structured Outputs)
- 출력 품질 테스트 및 개선
- AI 응답 검증 및 에러 처리

#### 🛠 주요 작업 파일
```
lib/ai/openai.ts                  # OpenAI 클라이언트 초기화
lib/ai/prompts.ts                 # 프롬프트 정의
lib/ai/schema.ts                  # JSON 스키마
lib/ai/generateMenu.ts            # 메인 AI 함수
lib/ai/validation.ts              # 출력 검증 (선택)
```

#### 💡 핵심 제공 함수
```typescript
export async function generateMenu(input: GenerateInput): Promise<GenerateOutput> {
  // OpenAI API 호출
  // 프롬프트 생성
  // Structured Outputs로 JSON 받기
  // 검증 및 반환
}
```
