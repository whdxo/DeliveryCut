## 🎯 주요 역할

### 1️⃣ UI/UX 디자인

#### 📌 담당 영역
서비스 전체 화면의 시각적 디자인 및 사용자 경험 설계

- **와이어프레임**: 각 화면의 레이아웃 구조 설계
  - 홈(입력), 결과, 히스토리, 로그인, 회원가입 화면
- **디자인 시스템 정의**: 색상, 타이포그래피, 간격, 컴포넌트 규칙
- **화면 디자인**: 모바일 + 데스크탑 반응형 디자인
- **브랜딩**: 로고, 아이콘, 전반적인 톤앤매너

#### 현재 디자인 시스템 (구현됨, 참고용)
```css
/* 색상 — tailwind.config.ts에 dc-* 클래스로 등록됨 */
Primary:        #3D8A5A  (dc-primary)     — 메인 초록
Primary Light:  #C8F0D8  (dc-primary-light) — 연초록 배경
Background:     #FAF9F6  (dc-bg)          — 전체 배경
Surface:        #FFFFFF  (dc-surface)     — 카드/패널 배경
Muted:          #F0EEE9  (dc-muted)       — 입력 필드 배경
Side:           #EDECEA  (dc-side)        — 사이드 영역
Border:         #D1D0CD  (dc-border)      — 구분선
Text:           #1A1918  (dc-text)        — 본문
Text Secondary: #6D6C6A  (dc-text-secondary) — 보조 텍스트
Text Muted:     #9C9B99  (dc-text-muted)  — 비활성 텍스트
```

---

### 2️⃣ 공통 컴포넌트 개발

#### 📌 담당 영역
여러 화면에서 공통으로 사용하는 UI 컴포넌트 구현 및 커스터마이징

- **레이아웃**: `NavBar`, `MobileBottomNav` (이미 구현됨, 유지 및 개선)
- **버튼 변형**: 기본, 아웃라인, 텍스트 버튼
- **입력 필드**: 텍스트 입력, 텍스트에어리어, 선택 버튼
- **카드**: 메뉴 카드, 히스토리 카드
- **모달**: 로그인 유도 모달 (이미 구현됨)
- **뱃지/태그**: 시간 뱃지, 도구 태그

#### 🛠 주요 작업 파일
```
app/layout.tsx                    # 전체 레이아웃 (폰트, 메타데이터)
app/globals.css                   # 전역 스타일 (CSS 변수)
components/ui/*                   # shadcn/ui 컴포넌트
components/shared/Header.tsx      # 헤더 (필요 시)
components/shared/PageLayout.tsx  # NavBar, MobileBottomNav (이미 구현)
```

---

### 3️⃣ 반응형 디자인 QA

#### 📌 담당 영역
모든 화면의 반응형 디자인 검수 및 수정

- **모바일** (375px~): 단일 컬럼, 하단 내비게이션
- **데스크탑** (1024px+): 3단 레이아웃 (사이드 | 960px 중앙 | 사이드)
- 각 화면에서 lg: 브레이크포인트 기준 전환 확인

## 📐 디자인 시스템 가이드

### 레이아웃 패턴 (공통)
```tsx
// 모든 페이지에서 동일하게 사용
<div className="min-h-screen bg-dc-bg">
  {/* 상단 NavBar */}
  <div className="sticky top-0 z-50 border-b border-dc-border bg-dc-surface">
    <NavBar variant="app" />
  </div>

  {/* 3단 Body */}
  <div className="flex w-full">
    {/* 왼쪽 사이드 (데스크탑만) */}
    <div className="flex-1 bg-dc-side border-r border-dc-border hidden lg:block" />

    {/* 중앙 콘텐츠 */}
    <div className="w-full lg:w-[960px] lg:flex-none px-5 lg:px-10 py-6">
      {/* 페이지 내용 */}
    </div>

    {/* 오른쪽 사이드 (데스크탑만) */}
    <div className="flex-1 bg-dc-side border-l border-dc-border hidden lg:block" />
  </div>

  {/* 하단 내비게이션 (모바일만) */}
  <MobileBottomNav />
</div>
```

### 카드 컴포넌트 패턴
```tsx
<div className="bg-dc-surface rounded-2xl border border-dc-border p-4 lg:p-5">
  {/* 카드 내용 */}
</div>
```

### 버튼 패턴
```tsx
{/* 기본(Primary) 버튼 */}
<button className="h-[52px] bg-dc-primary text-white font-bold rounded-xl hover:bg-[#2d6b45] transition-colors">
  버튼 텍스트
</button>

{/* 선택 토글 버튼 */}
<button className={`h-9 px-4 rounded-full text-[13px] font-medium transition-colors ${
  selected ? "bg-dc-primary text-white" : "bg-dc-muted text-dc-text-secondary hover:bg-dc-border"
}`}>
  옵션 텍스트
</button>
```

## 🚀 개발 시작 방법

```bash
# 1. 저장소 클론
git clone https://github.com/whdxo/DeliveryCut.git
cd DeliveryCut

# 2. 유경 브랜치로 이동
git checkout yukyung/#2

# 3. 패키지 설치
npm install

# 4. 환경변수 설정
cp .env.example .env.local
# .env.local 파일 열어서 Firebase API 키 팀장에게 받아 입력

# 5. 개발 서버 실행
npm run dev
# 브라우저에서 http://localhost:3000 확인
```

### shadcn/ui 컴포넌트 추가 방법
```bash
# 필요한 컴포넌트 추가
npx shadcn@latest add button
npx shadcn@latest add input
npx shadcn@latest add card
npx shadcn@latest add dialog   # 모달
npx shadcn@latest add badge    # 뱃지/태그

# 추가된 컴포넌트는 components/ui/ 폴더에 생성됨
```
