## 🎯 주요 역할

### 1️⃣ Frontend — 입력 화면 (홈 페이지)

#### 📌 담당 영역
사용자가 조건을 입력하는 메인 홈 화면 (`app/home/page.tsx`) 구현

- **시간 선택**: 5분 / 10분 / 15분 버튼 토글
- **조리 도구 선택**: 전자레인지 / 팬 / 에어프라이어 멀티 선택
- **재료 입력**: 자유 텍스트 입력 + 빠른 태그 버튼
- **기피 재료 입력**: 선택 항목 (optional)
- **"배달컷 메뉴 만들기" 버튼**: 재료 입력 시 활성화, 결과 페이지로 이동

#### 🛠 주요 작업 파일
```
app/home/page.tsx                 # 입력 화면 (홈)
components/forms/TimeSelector.tsx # 시간 선택 컴포넌트
components/forms/ToolSelector.tsx # 도구 선택 컴포넌트
components/forms/IngredientInput.tsx # 재료 입력 컴포넌트
```

#### 📐 화면 스펙 (디자인 참고)
- **모바일**: 단일 컬럼, 하단 고정 내비게이션
- **데스크탑**: 3단 레이아웃 (사이드 여백 | 960px 중앙 | 사이드 여백), 오른쪽에 팁 사이드바
- **스타일**: Tailwind `dc-*` 색상 클래스 사용 (globals.css, tailwind.config.ts 참고)

## 📋 데이터 타입 (합의된 인터페이스)

```typescript
// lib/types/api.ts

// 입력 (홈 화면 → API → AI)
export interface GenerateInput {
  timeLimitMin: 5 | 10 | 15
  tools: ('microwave' | 'pan' | 'airfryer')[]
  ingredientsText: string
  dislikedIngredientsText?: string
}

// 출력 (AI → API → 결과 화면)
export interface MenuOption {
  optionId: string
  title: string
  timeMin: number
  tools: string[]
  ingredients: string[]
  steps: string[]
  difficulty: string
}

export interface GenerateOutput {
  menuOptions: MenuOption[]           // 3개 메뉴 옵션
  ingredientsUsed: { [key: string]: number }
  threeDayPlan: {
    day: number
    breakfast: string
    lunch: string
    dinner: string
  }[]
  shoppingList: {
    item: string
    quantity: number
    unit: string
  }[]
}
```

## 🔄 협업 가이드

### 종태(팀장/AI)와
- `generateMenu(input: GenerateInput): Promise<GenerateOutput>` 함수 인터페이스 사전 합의
- AI 함수 완성 전까지는 Mock 데이터로 개발 진행
- API Route에서 함수 연동 시 에러 처리 함께 논의

### 영진(Fullstack 2)과
- `/api/generate` 응답 형식 공유 → 결과 화면에서 파싱
- `lib/types/api.ts` 타입 파일 함께 유지
- URL 파라미터 형식 합의: `/result?time=10분&tools=팬,전자레인지&ingredients=계란,두부`

### 유경(디자이너)과
- 입력 화면 디자인 전달받기 (색상, 간격, 컴포넌트 크기)
- shadcn/ui 컴포넌트 활용 여부 확인
- 모바일/데스크탑 반응형 스펙 확인

## 🚀 개발 시작 방법

```bash
# 1. 저장소 클론
git clone https://github.com/whdxo/DeliveryCut.git
cd DeliveryCut

# 2. 세종 브랜치로 이동
git checkout sejong/#3

# 3. 패키지 설치
npm install

# 4. 환경변수 설정
cp .env.example .env.local
# .env.local 파일 열어서 Firebase API 키 팀장에게 받아 입력

# 5. 개발 서버 실행
npm run dev
```
