## 🎯 주요 역할

### 1️⃣ Frontend — 결과 화면

#### 📌 담당 영역
AI가 추천한 메뉴를 보여주는 결과 화면 (`app/result/page.tsx`) 구현

- **메뉴 옵션 3개 카드**: 클릭으로 선택, 선택된 카드 하이라이트
  - 데스크탑: 3열 그리드 카드
  - 모바일: 세로 리스트
- **레시피 탭**: 재료 목록 + 순서별 조리 단계
- **3일 플랜 탭**: 탭 전환으로 3일치 식단 표시
- **장보기 목록**: 우측 사이드바 (데스크탑) / 하단 섹션 (모바일)
- **복사 기능**: 장보기 목록 클립보드 복사 버튼

#### 🛠 주요 작업 파일
```
app/result/page.tsx               # 결과 화면
components/results/MenuCard.tsx   # 메뉴 선택 카드
components/results/RecipeView.tsx # 레시피 상세
components/results/ThreeDayPlan.tsx # 3일 플랜
components/results/ShoppingList.tsx # 장보기 목록
components/shared/CopyButton.tsx  # 클립보드 복사 버튼
```

#### 📐 화면 스펙
- **URL**: `/result` — 세종의 홈 화면에서 파라미터 전달받음
- **데스크탑**: 메뉴 카드 3열 + 레시피/장보기 2단 레이아웃
- **모바일**: 메뉴 리스트 → 탭 선택 → 레시피 세로 스크롤

### 2️⃣ Frontend — 히스토리 화면

#### 📌 담당 영역
이전 AI 추천 결과를 모아보는 히스토리 화면 (`app/history/page.tsx`) 구현

- **필터 칩**: 전체 / 5분 이하 / 10분 / 15분 이상 (시간별 필터)
- **날짜 그룹 카드**: 날짜별로 묶어서 히스토리 표시
- **"다시 사용하기" 버튼**: 해당 결과를 다시 결과 화면으로 이동
- **Firebase 연동**: Firestore에서 사용자 히스토리 조회 (로그인 시)

#### 🛠 주요 작업 파일
```

```

## 🔐 Firebase 인증 함수 (이미 구현됨)

```typescript
// lib/firebase에서 import해서 사용
import { signUp, signIn, logOut, onAuthChange } from '@/lib/firebase'

// 회원가입
const { user, error } = await signUp(email, password)

// 로그인
const { user, error } = await signIn(email, password)

// 로그아웃
const { error } = await logOut()

// 로그인 상태 감지 (useEffect 안에서)
const unsubscribe = onAuthChange((user) => {
  setUser(user)
})
return () => unsubscribe()
```
