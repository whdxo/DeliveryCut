# 프로젝트 개요

## 🎯 한 줄 소개

**배달/외식이 습관이 된 20-30대 1인 가구**가 냉장고 재료와 시간/도구만 입력하면, AI가 **배달 대체 한 끼 3개 + 3일 식단 플랜 + 장보기 리스트**를 즉시 생성해주는 서비스

---

## 💡 왜 만들까?

### 문제점
1. **식비 증가**: 피곤하면 배달 시킴 → 월 30~50만원 지출
2. **결정 피로**: "뭘 먹지?" 고민 10분 → 결국 배달
3. **재료 낭비**: 장봐도 1-2번 쓰고 버림
4. **현실 제약 무시**: 기존 레시피는 "지금 가능한 조건" 안 봄

### 우리의 솔루션
- ✅ **시간 제약** (5/10/15분)만 입력
- ✅ **도구 제약** (전자레인지/원팬/에어프)만 선택
- ✅ **냉장고 재료** 대충 입력 (쉼표로 구분)
- 🎉 AI가 즉시 **배달 대체 메뉴 3개 + 레시피 + 3일 플랜 + 장보기 리스트** 생성

---

## 🎨 화면 구성 (3개)

### 1. 입력 화면 (30초 입력 목표)
```
┌─────────────────────────┐
│  시간: ○5분 ●10분 ○15분 │
│  도구: ☑전자레인지 ☑원팬 │
│  재료: [계란, 김치, 두부] │
│  [배달컷 메뉴 만들기]    │
└─────────────────────────┘
```

### 2. 결과 화면 - 메뉴 3개
```
┌─────────┐ ┌─────────┐ ┌─────────┐
│ 김치볶음 │ │ 계란찜  │ │ 덮밥    │
│ 10분    │ │ 10분    │ │ 10분    │
│ 원팬    │ │ 전자렌지 │ │ 원팬    │
└─────────┘ └─────────┘ └─────────┘
```

### 3. 상세 화면
- ✅ 선택한 메뉴의 **5줄 레시피 + 실패 방지 팁**
- ✅ **3일 식단 플랜** (재료 돌려쓰기)
- ✅ **최소 장보기 리스트** (부족한 것만)

## 🎯 MVP 범위 (5일)

### ✅ 반드시 구현 (Must Have)
1. 입력 화면 (시간/도구/재료)
2. AI 생성 (메뉴 3개 + 레시피 + 3일 플랜 + 장보기)
3. 결과 화면 (카드 + 레시피)
4. 복사 기능 (레시피, 장보기 리스트)

### ❌ 이번엔 안함 (Won't Have)
- 사진 인식 (OCR)
- 칼로리 분석
- 결제/커머스 연동
- 사용자 취향 학습

---

## 🏆 성공 기준

다음 시나리오가 작동하면 MVP 완성:

```
1. "10분 / 전자레인지+원팬 / 계란,김치,두부,양파" 입력
2. 생성 버튼 클릭 (5초 대기)
3. 메뉴 3개 카드로 출력
4. 하나 선택 → 5줄 레시피 + 팁 표시
5. 3일 플랜 + 장보기 리스트 함께 생성
6. 복사 버튼으로 카톡 공유 가능
```
