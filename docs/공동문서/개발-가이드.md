# 개발 가이드

## 🚀 빠른 시작 (5분)

### 1. 저장소 클론
```bash
git clone https://github.com/whdxo/DeliveryCut.git
cd DeliveryCut
```

### 2. 패키지 설치
```bash
npm install
```

### 3. 환경변수 설정
```bash
# .env.example을 복사하여 .env.local 생성
cp .env.example .env.local
```

`.env.local` 파일 열어서 API 키 입력:
```bash
# Firebase Configuration
NEXT_PUBLIC_FIREBASE_API_KEY=your-firebase-api-key-here
NEXT_PUBLIC_FIREBASE_AUTH_DOMAIN=deliverycut-3a439.firebaseapp.com
NEXT_PUBLIC_FIREBASE_PROJECT_ID=deliverycut-3a439
NEXT_PUBLIC_FIREBASE_STORAGE_BUCKET=deliverycut-3a439.firebasestorage.app
NEXT_PUBLIC_FIREBASE_MESSAGING_SENDER_ID=954345744841
NEXT_PUBLIC_FIREBASE_APP_ID=1:954345744841:web:2fa806f32c48d951bca018
NEXT_PUBLIC_FIREBASE_MEASUREMENT_ID=G-V1LG36C91X

# OpenAI API Key (AI 담당자에게 받기)
OPENAI_API_KEY=your_openai_api_key_here
```

### 4. 개발 서버 실행
```bash
npm run dev
```

브라우저에서 http://localhost:3000 접속

## 🛠 shadcn/ui 컴포넌트 추가 방법

프로젝트에 필요한 UI 컴포넌트 추가:

```bash

# 카드 추가
npx shadcn@latest add card

# 토스트 (알림) 추가
npx shadcn@latest add toast

# 여러 개 한 번에
npx shadcn@latest add button input textarea card toast skeleton checkbox
```

추가된 컴포넌트는 `components/ui/` 폴더에 생성됨.

## 🔐 환경변수 관리

### 클라이언트에서 접근 가능한 변수
`NEXT_PUBLIC_` 접두사 필수:
```bash
NEXT_PUBLIC_FIREBASE_API_KEY=...
NEXT_PUBLIC_FIREBASE_PROJECT_ID=...
```

사용:
```typescript
const apiKey = process.env.NEXT_PUBLIC_FIREBASE_API_KEY;
```

### 서버 전용 변수
접두사 없이:
```bash
OPENAI_API_KEY=sk-proj-...
```

사용 (API Route에서만):
```typescript
// app/api/generate/route.ts
const apiKey = process.env.OPENAI_API_KEY;
```

**중요**: 환경변수 변경 후 **서버 재시작** 필수!

## 🔥 Firebase 사용법

### Firebase 설정 완료 여부 확인
프로젝트에 Firebase가 이미 설정되어 있습니다:
- ✅ Firestore Database (Seoul 리전)
- ✅ Authentication (이메일/비밀번호)
- ✅ 환경변수 설정 완료

### 기본 사용법

#### 1. Firebase Import
```typescript
import { auth, db, signUp, signIn, logOut, saveMenuPlan } from '@/lib/firebase'
```

#### 2. 인증 (Authentication)
```typescript
// 회원가입
const { user, error } = await signUp(email, password)

// 로그인
const { user, error } = await signIn(email, password)

// 로그아웃
const { error } = await logOut()

// 현재 로그인 상태 감지
import { onAuthChange } from '@/lib/firebase'
onAuthChange((user) => {
  if (user) {
    console.log('로그인됨:', user.email)
  } else {
    console.log('로그아웃 상태')
  }
})
```

#### 3. Firestore (데이터베이스)
```typescript
import { saveMenuPlan, getUserMenuPlans, setDocument, getDocument } from '@/lib/firebase'

// 메뉴 플랜 저장
const { id, error } = await saveMenuPlan(userId, {
  menuOptions: [...],
  ingredients: {...},
  createdAt: new Date()
})

// 사용자의 메뉴 플랜 가져오기
const { data, error } = await getUserMenuPlans(userId)

// 일반 문서 저장
await setDocument('users', userId, { name: '홍길동', email: 'test@example.com' })

// 일반 문서 읽기
const { data, error } = await getDocument('users', userId)
```

#### 4. 사용 예시 (컴포넌트)
```typescript
'use client'
import { useState, useEffect } from 'react'
import { auth, onAuthChange, saveMenuPlan } from '@/lib/firebase'

export default function MyComponent() {
  const [user, setUser] = useState(null)

  useEffect(() => {
    const unsubscribe = onAuthChange((user) => {
      setUser(user)
    })
    return () => unsubscribe()
  }, [])

  const handleSave = async (menuData) => {
    if (!user) {
      alert('로그인이 필요합니다')
      return
    }

    const { id, error } = await saveMenuPlan(user.uid, menuData)
    if (error) {
      console.error('저장 실패:', error)
    } else {
      console.log('저장 성공! ID:', id)
    }
  }

  return <div>...</div>
}
```

## 🐛 트러블슈팅

### 1. 패키지 설치 오류
```bash
# 캐시 클리어 후 재설치
npm cache clean --force
rm -rf node_modules package-lock.json
npm install
```

### 2. 개발 서버 포트 충돌
```bash
# 3000번 포트가 사용 중이면
npm run dev -- -p 3001  # 다른 포트로 실행
```

### 3. TypeScript 에러
VS Code에서:
- `Cmd + Shift + P` (Mac) / `Ctrl + Shift + P` (Windows)
- "TypeScript: Restart TS Server" 선택

### 4. 환경변수 인식 안됨
- `.env.local` 파일이 프로젝트 **루트**에 있는지 확인
- 서버 재시작 (`Ctrl + C` 후 `npm run dev`)
- `NEXT_PUBLIC_` 접두사 확인 (클라이언트 사용 시)
