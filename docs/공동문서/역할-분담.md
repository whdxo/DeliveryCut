## 📋 역할 상세 설명

### 1️⃣ Fullstack Developer 1 (입력 화면 + API)

#### 📌 담당 영역
**Frontend**:
- 입력 화면 UI 구현 (홈 페이지)
  - 시간 선택 (5/10/15분)
  - 도구 선택 (전자레인지/팬/에어프라이어)
  - 재료 입력 (냉장고 재료)
  - 기피 재료 입력
  - "생성하기" 버튼

**Backend**:
- `/api/generate` API Route 구현
  - 클라이언트 요청 받기
  - AI 함수 호출 (AI 담당자 제공)
  - 응답 반환
  - 에러 처리

#### 🛠 주요 작업 파일
```
app/page.tsx                      # 입력 화면 (홈)
app/api/generate/route.ts         # AI 생성 API
components/forms/TimeSelector.tsx # 시간 선택
components/forms/ToolSelector.tsx # 도구 선택
components/forms/IngredientInput.tsx # 재료 입력
```

#### 📚 필요 스킬
- **Frontend**: React, TypeScript, Tailwind CSS, shadcn/ui
- **Backend**: Next.js API Routes, 환경변수 관리
- **통합**: AI 함수 호출, 에러 처리

#### ⏰ 예상 작업량
⭐⭐⭐⭐ (높음)

#### 🤝 협업 포인트
- **Designer와**: 입력 화면 디자인 받기, 컴포넌트 재사용
- **AI와**: `generateMenu()` 함수 인터페이스 합의
- **Fullstack 2와**: API 응답 형식 합의

### 2️⃣ Fullstack Developer 2 (결과 화면 + API)

#### 📌 담당 영역
**Frontend**:
- 결과 화면 UI 구현

- Vercel 배포

- **Frontend**: React, TypeScript, Tailwind CSS

### 3️⃣ AI/Prompt Engineer

#### 📌 담당 영역
- OpenAI API 통합
- 프롬프트 설계 및 최적화
  - System Prompt: 역할, 제약사항, 출력 형식
  - User Prompt: 사용자 입력 변환
- JSON 스키마 정의 (Structured Outputs)
- 출력 품질 테스트 및 개선
- AI 응답 검증 및 에러 처리

#### 🛠 주요 작업 파일
```
lib/ai/openai.ts                  # OpenAI 클라이언트 초기화
lib/ai/prompts.ts                 # 프롬프트 정의
lib/ai/schema.ts                  # JSON 스키마
lib/ai/generateMenu.ts            # 메인 AI 함수
lib/ai/validation.ts              # 출력 검증 (선택)
```

#### 📚 필요 스킬
- **AI**: OpenAI API 사용, Structured Outputs
- **프롬프트 엔지니어링**: System/User Prompt 설계
- **코딩**: TypeScript (또는 Python)
- **도메인 지식**: 요리, 재료, 시간 제약

#### ⏰ 예상 작업량

## 🤝 협업 가이드

### 공통 규칙
- **커뮤니케이션**: 막히면 30분 내로 팀원에게 물어보기
- **브랜치 전략**: 각자 브랜치에서 작업 후 PR
- **코드 리뷰**: 최소 1명 리뷰 후 Merge
- **타입 공유**: `lib/types/` 폴더에 공통 타입 정의

### 데이터 타입 예시 (합의 필요)
```typescript
// lib/types/api.ts

// 입력 (Fullstack 1 → AI)
export interface GenerateInput {
  timeLimitMin: 5 | 10 | 15;
  tools: ('microwave' | 'pan' | 'airfryer')[];
  ingredientsText: string;
  dislikedIngredientsText?: string;
}

// 출력 (AI → Fullstack 1,2)
export interface MenuOption {
  optionId: string;
  title: string;
  timeMin: number;
  tools: string[];
  ingredients: string[];
  steps: string[];
  difficulty: string;
}

export interface GenerateOutput {
  menuOptions: MenuOption[];
  ingredientsUsed: { [key: string]: number };
  threeDayPlan: { day: number; breakfast: string; lunch: string; dinner: string }[];
  shoppingList: { item: string; quantity: number; unit: string }[];
}
```

## 🆘 문제 해결

### 역할이 겹치거나 작업량이 불균형하다면?
- 팀 회의에서 재조정
- 작업 세분화 또는 교환

### 기술적으로 막혔다면?
1. 공식 문서 확인
2. 팀원에게 질문 (30분 이내)
3. 전체 팀 공유 (1시간 이상)

### 일정이 늦어진다면?
- 우선순위 재조정 (히스토리 기능 생략 등)
- 역할 간 도움 요청
