## 🤝 협업 포인트

### Frontend ↔ Backend
- **데이터 전달**: API 응답 형식 합의
- **에러 처리**: 로딩/에러 상태 UI
- **타입 공유**: TypeScript 인터페이스

### Backend ↔ AI
- **함수 인터페이스**: `generateMenu(input)` 형식 확정
- **OpenAI API 키**: 공유 및 환경변수 설정
- **JSON 스키마**: 출력 형식 협의

### Frontend ↔ Frontend
- **공통 컴포넌트**: 재사용 가능한 UI
- **상태 관리**: 입력 → 결과 데이터 전달
- **라우팅**: 페이지 전환 방식
